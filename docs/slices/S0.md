- `web/` memakai npm + `package-lock.json`; Node 24 di CI & container (`.nvmrc`/`engines`).

- Perintah artisan baru berprefix `cc:` dan hanya menghasilkan fixtures (tidak mengubah fitur).

### A. Kerangka web — selesai bila

1. `web/` Next.js 16.4.6 App Router, TypeScript strict, ESLint + Prettier, Vitest; dependensi tampilan dikunci
   **persis** sama dengan `sigap/package-lock.json` (Tailwind & `@tailwindcss/postcss` 4.0.8, `tailwindcss-animate`,
   `tailwind-merge`, `lucide-react`, `@fontsource/*`, Radix, `@headlessui/react`, `clsx`, `class-variance-authority`,
   `@tanstack/react-table`, `leaflet`, `react-leaflet`); dependensi server dikunci persis juga (`zod`, `pino`,
   `drizzle-orm`, `drizzle-kit`, `pg`, `bcryptjs`, `vitest`).
2. `src/app/globals.css` = salinan utuh `sigap/resources/css/app.css`; tanpa `next/font`, tanpa `next/image`.
3. Root layout: `<html lang="en">`, `<body class="font-sans antialiased">`, skrip tema/a11y inline sebelum paint
   (identik dengan `sigap/resources/views/app.blade.php`), format judul `"{judul} - Contact Center"`.
4. `src/server/env.ts` (Zod, gagal start bila kunci wajib kosong), `src/server/log.ts` (pino, redaksi NIK/email/
   telepon), struktur folder sesuai rencana utama §1/§9.2.
5. **Bukti CSS identik**: `npm run cek:css` membandingkan CSS hasil build Next.js dengan CSS hasil build Laravel
   (`sigap/public/build/assets/app-*.css`) setelah normalisasi; hasil: identik, atau daftar selisih yang dijelaskan.
6. `lint`, `typecheck`, `test`, `build` lulus.

### B. Kompatibilitas Laravel — selesai bila

`laravel-crypt.ts` (encrypt/decrypt `encryptString`, multi kunci), `nik.ts` (hash HMAC & mask), verifikasi bcrypt
`$2y$`, dekripsi cookie Laravel (`EncryptCookies` + prefix HMAC), unserialize/serialize payload sesi PHP, dan pembaca
sesi (payload → user id, cek `password_hash_web`) — semuanya lulus vektor yang dihasilkan `cc:ekspor-fixture-kripto`
dari Laravel asli (kunci uji, bukan kunci produksi).

### C. Suite paritas — selesai bila

1. `parity/` proyek Playwright TS dengan `BASE_URL`; target Laravel lokal = `php artisan sigap:e2e-setup` + `serve`
   di SQLite (seperti `sigap/playwright.config.ts`).
2. Test paritas S1 (halaman statis + redirect 301) dan baseline visual S1 (3 viewport × terang/gelap) **hijau
   terhadap Laravel**.
3. `cc:ekspor-fixture` menghasilkan vektor JSON: SLA, transisi status tiket, format nomor tiket & normalisasi lacak,
   skor SKM survei — di `parity/fixtures/`.

### D. CI & container — selesai bila

1. Workflow `web.yml` (lint, typecheck, test, build untuk `web/`) dan `paritas.yml` (manual/PR: jalankan suite
   paritas terhadap Laravel lokal di runner), dengan izin minimal, action dipin ke SHA, lulus `agentic-actions-auditor`.
2. `deploy/next/Dockerfile` (Node 24, `output: standalone`, non-root, filesystem read-only) dan
   `deploy/next/compose.yml` (web, worker, valkey, pgbouncer) — **belum** dijalankan di server.
3. `scripts/cek-binary-native.sh`: menguji SWC/Next build, `sharp`, Valkey di CPU tanpa AVX — dijalankan di server
   hanya setelah persetujuan pemilik proyek.
